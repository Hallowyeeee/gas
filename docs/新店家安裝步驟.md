# 新店家安裝步驟

一家店 = 一台主電腦 + 任意台分機 + 師傅手機。每家店的資料各自放在自己的主電腦，互不相通。

## 一、主電腦（每家店做一次，約 15 分鐘）

1. 下載最新版 `gas-setup.exe`（GitHub Releases 最新的 V 開頭版本），雙擊安裝，一路按「下一步」。
2. 程式第一次打開會問「這台電腦是？」→ 按 **主電腦** → 確定。
3. Windows 跳出「是否允許此 App 變更」→ 按 **是**（這是讓店裡分機連進來的防火牆設定）。
4. 程式自動重開後，建立老闆帳號（名字、帳號、密碼）。
5. 設定固定外面網址（分機在外面、師傅手機都要用）：
   1. 到 Cloudflare（登入 hallowyeeee.com 的帳號）→ Zero Trust → Networks → Tunnels → **Create a tunnel** → 選 Cloudflared → 名字打店名。
   2. 複製畫面上那段安裝指令（裡面有 `eyJ` 開頭的一長串），**不用**照它的指令安裝。
   3. 「Public Hostname」：Subdomain 打店名英文（例如 `shop2`），Domain 選 `hallowyeeee.com`，Service 選 `HTTP`、URL 打 `localhost:8080` → 儲存。
   4. 回到瓦斯行程式「設定 → 手機網址 → 固定網址設定」：網址打 `shop2.hallowyeeee.com`，金鑰貼上剛剛複製的那段 → 儲存並連線。
6. 「設定 → 帳號」新增店員、師傅帳號。
7. 「設定 → 備份」把備份資料夾設到 Google 雲端硬碟。
8. 插上來電盒（USB），「設定 → 來電顯示」看到「已連線」就好。

## 二、分機

### 店裡的電腦
1. 安裝 `gas-setup.exe`。
2. 第一次打開選 **分機** → 會自己找到店裡的主電腦，直接出現登入畫面，用自己的帳號登入。

### 外面的電腦（例如老闆家裡）
1. 在主電腦「設定 → 這台電腦」按 **複製連線碼**，用 LINE 傳給自己。
2. 外面的電腦安裝 `gas-setup.exe`，第一次打開選 **分機**，貼上連線碼 → 連線 → 登入。
3. 筆電如果曾經在店裡連過，到外面會自動連，不用連線碼。

## 三、師傅手機

主電腦「設定 → 手機網址」有 QR Code，師傅用相機掃 → 登入 → 「分享 → 加入主畫面」→ 照畫面開通知。

## 常見問題

| 狀況 | 怎麼辦 |
|---|---|
| 分機在店裡，卻顯示「走外面網路」 | 主電腦「設定 → 這台電腦」按「讓店裡電腦連進來」，Windows 問就按「是」 |
| 分機顯示「連不到主電腦」 | 主電腦有沒有開著、有沒有網路；外面的電腦確認連線碼是這家店的 |
| 主電腦換了一台 | 新主電腦裝好、把舊資料庫 `gas.db` 複製過去；分機在店裡會自動找到新主電腦，外面的分機要重新貼連線碼（設定 → 這台電腦 → 連線設定） |
| 不小心選錯主電腦/分機 | 設定 → 這台電腦 可以改 |

程式都會在半夜 2～5 點自動更新，不用一台一台裝。
