# 試跑教學

這一版可以：記單、派單、師傅手機收單和回報送達、每日對帳。
第一次試跑照下面 1～6 做，大約 20 分鐘。

## 1. 下載

1. 打開 GitHub 專案的「Releases（最新版）」頁面，下載 `gas.exe`。
2. 在店裡電腦建一個資料夾，例如 `C:\瓦斯行`，把 `gas.exe` 放進去。
   - 資料庫 `gas.db`、紀錄檔 `gas.log`、通道程式 `cloudflared.exe` 都會自動放在這個資料夾。

## 2. 第一次啟動

1. 雙擊 `gas.exe`。
   - Windows 可能跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。（程式沒有花錢買數位簽章才會這樣）
   - 可能跳出防火牆詢問：勾「私人網路」→「允許」，店裡 WiFi 的手機才連得到。
2. 會出現一個黑色視窗（這就是後端，**不要關掉**，縮小就好），瀏覽器會自動打開 `http://localhost:8080`。
3. 填你的名字、登入帳號、密碼，按「建立並登入」。這一步只能在這台電腦上做，外面的人沒辦法搶先設定。

## 3. 手機連線

1. 第一次啟動時程式會自動下載 Cloudflare 的通道程式（約 40MB），等 1 分鐘左右。
2. 「設定」頁的「📱 手機網址」會出現一個 `https://xxxx.trycloudflare.com` 網址和 QR Code。
3. 用手機相機掃 QR Code，就能看到登入頁。
4. 店裡 WiFi 底下也可以用卡片下方的 `http://192.168...:8080` 網址。

> 免費通道每次電腦重開或程式重開都會換網址，要重新掃。之後買網域就會變成固定網址。

## 4. 備份設定

1. 安裝 Google 官方的「Google 雲端硬碟（電腦版）」並登入，電腦會多一個 G 槽。
2. 在 G 槽「我的雲端硬碟」裡建一個資料夾，例如 `瓦斯行備份`。
3. 回到系統的「設定」→「💾 備份」，填入 `G:\我的雲端硬碟\瓦斯行備份`，按「儲存資料夾」，再按「立刻備份一次」。
4. 之後程式開著時每天會自動備份一次，保留最近 60 份。

## 5. 建資料、試一張單

1. 「設定」→「＋ 新增師傅 / 店員」：建一個師傅帳號（例如 阿明 / ming / 密碼）。
2. 「商品」→「＋ 新商品」：
   - 先建「20kg 空瓶」，分類選「空瓶」。
   - 再建「20kg 家用瓦斯」，分類「瓦斯」，填售價、進價，「對應空瓶」選 20kg 空瓶。
   - 其他規格（4kg、16kg、50kg）、爐具、耗材照同樣方式新增。
3. 「＋記單」（或按 F2）：輸入客戶電話 → 找不到就按「＋ 新客戶」→ 按 ＋ 選幾瓶 → 選師傅 → 按「建立訂單」或 Enter。
4. 師傅手機：掃「設定」頁的 QR Code → 用師傅帳號登入 → 按「開啟通知」→ 加到主畫面（iPhone：Safari 分享 →「加入主畫面」，要從主畫面打開才收得到通知）。
5. 再派一張單，師傅手機會響、跳通知。師傅按「送達回報」填收了多少錢、回收幾個空瓶。
6. 「對帳」：看每位師傅應收、回報、押瓶費、應交；師傅交錢時在右邊輸入金額按「交帳」，對不上的整列會變紅。

> 師傅在沒訊號的地方按送達也沒關係，手機會先記著，有網路時自動送出（畫面上會顯示「傳送中」）。

## 6. 每天怎麼用

- 早上開電腦後雙擊 `gas.exe`，晚上可以不關（開著師傅才收得到單）。
- 想開機自動啟動：按 `Win + R`，輸入 `shell:startup`，把 `gas.exe` 的「捷徑」放進打開的資料夾。

## 出問題時

- 黑色視窗跳出錯誤：拍照或把 `gas.log` 傳給我。
- 「埠號 8080 被占用」：代表程式已經開著了，直接開瀏覽器到 `http://localhost:8080` 就好。
- 手機網址一直沒出現：確認電腦有網路；公司或店裡的網路如果擋 Cloudflare，就先用店裡 WiFi 網址。
