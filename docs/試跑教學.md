# 試跑教學

這一版可以：記單、派單、師傅手機收單和回報送達、每日對帳。
第一次試跑照下面 1～6 做，大約 20 分鐘。

## 1. 安裝

1. 打開 GitHub 專案的「Releases（最新版）」頁面，下載 `gas-setup.exe`。
2. 雙擊安裝，一路按「下一步」。預設裝在 `C:\瓦斯行`，桌面會有店徽捷徑。
   - 「開機自動啟動」建議打勾：電腦開機後程式會自動在右下角執行，師傅隨時收得到單。
   - 資料庫 `gas.db`、備份 `backups`、紀錄 `gas.log` 都放在 `C:\瓦斯行`。
3. 解除安裝：Windows「設定 → 應用程式」找「瓦斯行管理系統」。資料庫和備份會保留，不會被刪。

> 之前手動放在下載資料夾的 `gas.exe` 可以刪掉。若那邊已經有資料，把 `gas.db` 複製到 `C:\瓦斯行` 就能接著用（複製前先把兩邊的程式都結束）。

## 2. 第一次啟動

1. 安裝完會自動打開，之後點桌面的「瓦斯行管理系統」。
   - Windows 可能跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。（程式沒有花錢買數位簽章才會這樣）
   - 可能跳出防火牆詢問：勾「私人網路」→「允許」，店裡 WiFi 的手機才連得到。
2. 會跳出「瓦斯行管理系統」程式視窗，右下角工作列也會多一個店徽小圖示。
   - 按視窗右上角 X 只會把視窗藏起來，程式還在背景跑（師傅才收得到單）。點右下角小圖示就能叫回來。
   - 真的要關掉：在右下角小圖示按右鍵 →「結束程式」。
   - 再雙擊一次 `gas.exe` 也只會把原本的視窗叫出來，不會開兩個。
3. 填你的名字、登入帳號、密碼，按「建立並登入」。這一步只能在這台電腦上做，外面的人沒辦法搶先設定。

## 3. 手機連線

1. 通道程式已經包在安裝檔裡，打開後大約 10 秒就會連上。
2. 「設定」頁的「📱 手機網址」會出現一個 `https://xxxx.trycloudflare.com` 網址和 QR Code。
3. 用手機相機掃 QR Code，就能看到登入頁。
4. 店裡 WiFi 底下也可以用卡片下方的 `http://192.168...:8080` 網址。

> 免費通道每次電腦重開或程式重開都會換網址，要重新掃。之後買網域就會變成固定網址。

## 4. 備份設定

1. 安裝 Google 官方的「Google 雲端硬碟（電腦版）」並登入，電腦會多一個 G 槽。
2. 在 G 槽「我的雲端硬碟」裡建一個資料夾，例如 `瓦斯行備份`。
3. 回到系統的「設定」→「💾 備份」，填入 `G:\我的雲端硬碟\瓦斯行備份`，按「儲存資料夾」，再按「立刻備份一次」。
4. 之後程式開著時每天會自動備份一次，保留最近 60 份。

## 5. 建資料、試一張單

1. 「設定」→「＋ 新增師傅 / 店員」：建一個師傅帳號（例如 阿明 / ming / 密碼）。
2. 「商品」→「＋ 新商品」：
   - 先建「20kg 空瓶」，分類選「空瓶」。
   - 再建「20kg 家用瓦斯」，分類「瓦斯」，填售價、進價，「對應空瓶」選 20kg 空瓶。
   - 其他規格（4kg、16kg、50kg）、爐具、耗材照同樣方式新增。
3. 「＋記單」（或按 F2）：輸入客戶電話 → 找不到就按「＋ 新客戶」→ 按 ＋ 選幾瓶 → 選師傅 → 按「建立訂單」或 Enter。
4. 師傅手機：掃「設定」頁的 QR Code → 用師傅帳號登入 → 按「開啟通知」→ 加到主畫面（iPhone：Safari 分享 →「加入主畫面」，要從主畫面打開才收得到通知）。
5. 再派一張單，師傅手機會響、跳通知。師傅按「送達回報」填收了多少錢、回收幾個空瓶。
6. 「對帳」：看每位師傅應收、回報、押瓶費、應交；師傅交錢時在右邊輸入金額按「交帳」，對不上的整列會變紅。

> 師傅在沒訊號的地方按送達也沒關係，手機會先記著，有網路時自動送出（畫面上會顯示「傳送中」）。

## 6. 每天怎麼用

- 有勾「開機自動啟動」的話什麼都不用做，程式會在右下角自己跑。
- 電腦晚上可以不關（開著師傅才收得到單）。

## 6-1. 從舊系統（捷程 easy88）抓客戶資料

1. 在瓦斯行程式「設定」找到「📥 從舊系統抓客戶資料」，把「📥 抓到瓦斯行」按鈕拖到 Chrome 的書籤列（按 Ctrl+Shift+B 打開書籤列）。
2. 每次登入舊系統後，點一下書籤列的「📥 抓到瓦斯行」。
3. 之後客人來電、舊系統跳到客戶頁時，按 **F12**：右上角閃一下「✓ 已送到瓦斯行」，瓦斯行程式跳出確認視窗。
4. 看一下資料，按 **Enter** 存，**Esc** 不存。同一位客人再按一次 F12 只會補新的送貨紀錄，不會重複。
5. 第一次如果 Chrome 說「已封鎖彈出式視窗」，按網址列右邊的圖示選「一律允許」。

存下來的東西：客戶資料（電話已存在就更新）、桶子結餘（借走／寄放）、舊送貨紀錄、出桶鋼瓶、舊售價（可設成特價），還會用舊紀錄自動算「大約幾天換一次瓶」。每天第一次存之前會自動備份資料庫。

## 7. 更新程式

- 有新版時，「設定」頁和上方選單會出現「⬆ 有新版」。
- 到「設定」→「🔄 程式更新」按「檢查更新」，看得到更新內容；按「立即更新」會先自動備份，再下載新版、自動重開，大約 1 分鐘。資料都會保留。
- 更新只能用老闆帳號、在店裡電腦上按。

## 出問題時

- 跳出錯誤視窗：拍照或把 `gas.log` 傳給我。
- 「埠號 8080 被占用」：代表程式已經開著了，直接開瀏覽器到 `http://localhost:8080` 就好。
- 手機網址一直沒出現：確認電腦有網路；公司或店裡的網路如果擋 Cloudflare，就先用店裡 WiFi 網址。
